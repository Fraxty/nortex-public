# 12 Effizientes Arbeiten

[Zurück](11-first-project.md) · [Inhaltsverzeichnis](README.md) · [Weiter: FAQ](13-faq-and-troubleshooting.md)

- **Kreislauf**: schreiben → Strg+F5 → Compiler Log prüfen → korrigieren. Die IDE speichert vor jedem Build selbst.
- **Befehlspalette** (Strg+Umschalt+P) statt Menüsuche.
- **Fensteraufteilung**: Editor mit Strg+\ teilen (Quelltext neben Beispiel/Test). Console mit Strg+J ein-/ausblenden, Strg+Umschalt+M/U springt zum passenden Reiter. Zen-Modus blendet Nebenelemente aus.
- **Projekte**: einen Ordner je Projekt, optional `nortex.toml` ([Manifest](../build-system/manifest.md)) für Projektname, Einstiegsdatei und Build-Optionen; Fenstertitel und Statusleiste zeigen dann den Projektnamen.
- **Navigation**: Strg+P (Datei öffnen), Projektsuche Strg+Umschalt+F, Strg+Tab zwischen Tabs, Strg+F im Dokument.
- **Zeilen bearbeiten** mit Alt+↑/↓, Strg+/ und Strg+D statt Kopieren/Einfügen.
- **Übersicht**: kleine Funktionen, aussagekräftige Namen; die Autovervollständigung nutzt Bezeichner des Dokuments.
- Immer speichern, bevor die IDE geschlossen wird; es gibt keine Wiederherstellung ungespeicherter Tabs.

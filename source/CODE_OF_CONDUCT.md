# Verhaltenskodex / Code of Conduct

Wir erwarten respektvollen, sachlichen Umgang in Issues, Pull Requests und Diskussionen. Beleidigungen, Belästigung, Diskriminierung und das Veröffentlichen privater Informationen Dritter sind nicht erlaubt.
*We expect respectful, constructive interaction. Harassment, discrimination, insults and publishing others' private information are not acceptable.*

Verstöße können den Maintainer über die private GitHub-Funktion oder per Meldung an **NorisTec@protonmail.com** erreichen. **REVIEW REQUIRED:** Ein formales Durchsetzungsverfahren ist nicht festgelegt. Anpassung an einen etablierten Standard (z. B. Contributor Covenant) ist möglich, sobald der Inhaber das entscheidet.

# Mitwirken

1. Erstelle einen eigenen Branch für deine Änderung.
2. Halte Rust-Code mit `cargo fmt` formatiert.
3. Prüfe Änderungen mit `cargo check --workspace` und `cargo test --workspace`.
4. Ergänze Tests und Dokumentation, wenn sich Verhalten oder Syntax ändern.
5. Beschreibe in deinem Pull Request Motivation, Änderung und mögliche Folgen.

Bitte keine unfertigen Sprachfunktionen als bereits unterstützt dokumentieren.

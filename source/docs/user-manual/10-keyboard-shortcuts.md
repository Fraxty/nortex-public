# 10 Tastenkombinationen

[Zurück](09-settings-and-customization.md) · [Inhaltsverzeichnis](README.md) · [Weiter: Praktischer Einstieg](11-first-project.md)

Die Tasten gelten, solange die Befehlspalette geschlossen ist. Die Belegung lässt sich nicht ändern. Mit * markierte Kürzel erscheinen nicht in der Hilfe-Übersicht.

## Allgemeine Bedienung

| Taste | Funktion |
|---|---|
| Strg+Umschalt+P, F1 | Befehlspalette |
| Strg+Z | Rückgängig |
| Strg+Y, Strg+Umschalt+Z* | Wiederholen |
| Strg+Umschalt+X* | Erweiterungen – zeigt nur „Erweiterungen: nicht implementiert.“ |
| F11 | Zen-Modus ein/aus |
| Esc | Zen-Modus verlassen (wenn aktiv) |

In der Palette: tippen filtert, Pfeiltasten wählen, Enter führt aus, Esc schließt. Verfügbare Befehle: Build & Run, Toggle Theme, Clear Console, Toggle Zen Mode, Open File, Save File, Split Editor Columns / Rows / 2x2 Grid, Editor Single Layout, Close Editor Pane, Toggle Minimap.

## Dateiverwaltung

| Taste | Funktion |
|---|---|
| Strg+N | Neue Datei |
| Strg+S | Speichern |
| Strg+Umschalt+S | Speichern unter (Dateidialog) |
| Strg+P | „Schnellöffnen“: öffnet den Windows-Dateidialog (keine Dateiliste mit Suche) |
| Strg+Tab* | nächster Tab |

## Editor

| Taste | Funktion |
|---|---|
| Strg+F | Suchen |
| Strg+H | Ersetzen |
| Strg+/ | Zeilenkommentar ein/aus |
| Strg+D | nächstes Vorkommen auswählen |
| Alt+↑ / Alt+↓ | Zeile verschieben |
| Umschalt+Alt+↓ | Zeile duplizieren |
| F2 | Symbol umbenennen (aktuelle Datei) |
| Strg+Alt+M | Minimap ein/aus |
| Strg+Alt+B | `main`-Gerüst einfügen |
| ↑ ↓, Tab/Enter, Esc | im Vorschlags-Popup: wählen, übernehmen, schließen |
| Enter, Umschalt+Enter, Esc | im Suchfeld: nächster, vorheriger Treffer, schließen |

## Terminal und Console

| Taste | Funktion |
|---|---|
| Strg+L | Terminalanzeige löschen (wenn der Terminal-Reiter aktiv ist) |
| Enter | Befehl senden |
| Strg+Umschalt+M* | Compiler Log (Probleme) zeigen |
| Strg+Umschalt+U* | Runtime Output zeigen |

## Build, Ausführung und Debugging

| Taste | Funktion |
|---|---|
| Strg+F5 | Build & Run |
| Strg+Umschalt+B | Build & Run (identisch; kein reiner Build) |
| F5 | „Debugging starten“: öffnet das Debugger-Panel und meldet, dass schrittweises Debugging nicht verfügbar ist |
| Umschalt+F5* | Meldung „Abbrechen laufender Programme ist nicht implementiert.“ |
| F9 | Haltepunkt in der Cursorzeile setzen/entfernen ([Kapitel 8](08-debugging.md)) |

## Menü-Kürzel

Die Menüs zeigen Kürzel nur dort, wo sie im Menütext stehen; die Einträge sind in [Kapitel 3](03-interface-overview.md#menüleiste) aufgelistet. Zusätzlich gelten Strg+X, Strg+C, Strg+V und Strg+A direkt im Editor. *Hilfe → Tastatur-Kürzel* öffnet ein Fenster mit der Kürzelübersicht, *Hilfe → NORTEX Code-Handbuch* das Handbuch.

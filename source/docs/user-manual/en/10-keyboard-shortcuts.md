# 10 Keyboard shortcuts

[Back](09-settings-and-customization.md) · [Contents](README.md) · [Next: First steps](11-first-project.md)

The keys apply while the command palette is closed. The assignment cannot be changed. Shortcuts marked * do not appear in the help overview.

## General

| Key | Function |
|---|---|
| Ctrl+Shift+P, F1 | Command palette |
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z* | Redo |
| Ctrl+Shift+X* | Extensions – only shows "Extensions: not implemented." |
| F11 | Toggle Zen mode |
| Esc | Leave Zen mode (when active) |

In the palette: typing filters, arrow keys select, Enter runs, Esc closes. Available commands: Build & Run, Toggle Theme, Clear Console, Toggle Zen Mode, Open File, Save File, Split Editor Columns / Rows / 2x2 Grid, Editor Single Layout, Close Editor Pane, Toggle Minimap.

## File management

| Key | Function |
|---|---|
| Ctrl+N | New file |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as (file dialog) |
| Ctrl+P | "Quick open": opens the Windows file dialog (no searchable file list) |
| Ctrl+Tab* | next tab |

## Editor

| Key | Function |
|---|---|
| Ctrl+F | Find |
| Ctrl+H | Replace |
| Ctrl+/ | Toggle line comment |
| Ctrl+D | select next occurrence |
| Alt+↑ / Alt+↓ | Move line |
| Shift+Alt+↓ | Duplicate line |
| F2 | Rename symbol (current file) |
| Ctrl+Alt+M | Toggle minimap |
| Ctrl+Alt+B | Insert `main` skeleton |
| ↑ ↓, Tab/Enter, Esc | in the suggestion popup: select, accept, close |
| Enter, Shift+Enter, Esc | in the search field: next, previous match, close |

## Navigation and side bar

| Key | Function |
|---|---|
| Ctrl+Shift+E* | Explorer |
| Ctrl+Shift+F* | Search |
| Ctrl+Shift+G* | Git |
| Ctrl+Shift+D* | Debugger panel |
| Ctrl+1 … Ctrl+4* | Editor pane 1–4 |
| Ctrl+Alt+←/→/↑/↓*, Alt+←/→* | Focus neighboring pane |

## Terminal and console

| Key | Function |
|---|---|
| Ctrl+L | Clear terminal display (when the Terminal tab is active) |
| Enter | Send command |
| Ctrl+Shift+M* | Show Compiler Log (problems) |
| Ctrl+Shift+U* | Show Runtime Output |

## Build, run and debugging

| Key | Function |
|---|---|
| Ctrl+F5 | Build & Run |
| Ctrl+Shift+B | Build & Run (identical; no build-only mode) |
| F5 | "Start debugging": opens the Debugger panel and reports that step-by-step debugging is unavailable |
| Shift+F5* | Message "Cancelling running programs is not implemented." |
| F9 | Set/remove breakpoint on the cursor line ([Chapter 8](08-debugging.md)) |

## Panels and windows

| Key | Function |
|---|---|
| Ctrl+B | Toggle side bar |
| Ctrl+J | Toggle console |
| Ctrl+Shift+L* | Toggle sidecar |
| Ctrl+\ , Ctrl+Shift+2* | two columns |
| Ctrl+Shift+\* , Ctrl+Shift+3* | two rows |
| Ctrl+Shift+4* | 2×2 grid |
| Ctrl+Shift+W* | close active pane |
| Ctrl+mouse wheel | UI zoom |

## Menu shortcuts

The menus show shortcuts only where they appear in the menu text; the entries are listed in [Chapter 3](03-interface-overview.md#menu-bar). In addition Ctrl+X, Ctrl+C, Ctrl+V and Ctrl+A apply directly in the editor. *Help → Keyboard shortcuts* opens a window with the shortcut overview, *Help → NORTEX Code manual* opens the manual.
